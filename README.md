# OBS 레이싱 모션 0.6.0

게임 텔레메트리를 **OBS 플러그인이 직접 수신**하고, 소스를 좌우·상하로 이동시키거나 2D 회전시킵니다. 전후 가속·제동은 확대·축소와 상하 쏠림으로 표현합니다. 전체 강도와 축별 강도를 소스마다 조절할 수 있습니다. 기존 Python 프로그램이나 VMC/OSC 중계는 필요 없습니다.

## 지원 구성

Windows x64용입니다. **OBS Studio 32.0.2 / Windows 11 / Direct3D 11 / SDR**에서 빌드·렌더링을 검증했습니다. 다른 OBS 버전과 HDR은 검증하지 않았습니다.

| 게임 | 직접 수신 방식 | 필요한 설정 |
|---|---|---|
| **Euro Truck Simulator 2** | 게임 SDK DLL → 공유 메모리 → OBS | 포함된 게임용 DLL 설치 |
| American Truck Simulator | 같은 SDK DLL → 공유 메모리 | 포함된 게임용 DLL 설치 |
| Assetto Corsa / Competizione | 게임 공유 메모리 | 게임 실행 후 주행 |
| Forza Horizon / Motorsport | 게임 Data Out UDP | 주소·포트 일치 |
| Forza Horizon 6 | 기존 프로그램의 FH6 패킷 형식 | 주소·포트 일치 |
| EA Sports F1 23 / 24 / 25 | 게임 UDP 텔레메트리 | 해당 연도 형식, 주소·포트 일치 |

기존 텔레메트리 브리지의 게임 수신 형식을 이식했습니다. FH6 형식은 실게임 패킷으로 재확인해야 합니다. 위 목록은 수신 구현 목록이며 모든 게임에서 실주행 검증을 마쳤다는 뜻은 아닙니다.

## 설치

OBS와 대상 게임을 종료하고 배포 ZIP 전체를 폴더에 풉니다. `START-HERE.txt`에 빠른 시작 안내가 있습니다.

| 실행 파일 | 설치 대상 |
|---|---|
| `Install-OBS.cmd` | OBS 플러그인 |
| `Install-ETS2.cmd` | OBS 플러그인 + 선택한 유로트럭 2 폴더의 게임 DLL |
| `Install-ATS.cmd` | OBS 플러그인 + 선택한 아메리칸 트럭 폴더의 게임 DLL |

해당 파일을 실행하세요. 게임용 설치에서는 `bin/win_x64`가 들어 있는 게임 최상위 폴더를 선택합니다. 쓰기 권한 오류가 나면 실행 파일을 우클릭하여 **관리자 권한으로 실행**하세요. 폴더 선택을 취소하면 파일을 설치하지 않습니다. 설치 실패 시 창에 표시된 오류를 확인하세요.

수동 설치도 가능합니다.

1. ZIP 안의 `obs-racing-motion` 폴더를 `C:/ProgramData/obs-studio/plugins/` 아래로 복사합니다.
2. 유로트럭은 `truck/racing-motion-scs.dll`을 **게임 폴더의 `bin/win_x64/plugins/`** 에 복사합니다. `plugins` 폴더가 없으면 만듭니다. ATS도 같습니다.
3. OBS와 게임을 시작합니다. SCS 게임이 SDK 플러그인 안내를 표시하면 확인합니다.

PowerShell 설치 스크립트로 같은 작업을 할 수 있습니다(설치 위치의 쓰기 권한이 필요합니다).

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -ETS2Path 'C:\Program Files (x86)\Steam\steamapps\common\Euro Truck Simulator 2'
```

게임 경로 인수를 생략하면 OBS 플러그인만 설치합니다. 스크립트는 배포 파일 해시를 확인하고, 기존에 설치된 **이 플러그인의 파일만** 백업·교체합니다. 장면·프로필과 다른 플러그인은 수정하지 않습니다.

백업 위치는 `%LOCALAPPDATA%/OBSRacingMotion/backups/`입니다. 포터블 OBS는 자동 설치 대상이 아닙니다. 해당 OBS의 모듈 배치 규칙에 맞춰 DLL/data를 수동 설치해야 합니다.

제거하려면 OBS·게임 종료 후 `C:/ProgramData/obs-studio/plugins/obs-racing-motion/` 폴더와 게임에 설치한 `racing-motion-scs.dll`만 삭제합니다.

## 사용

1. OBS에서 움직일 소스를 우클릭 → **필터 → 효과 필터의 + → 레이싱 모션 — 게임 직접 수신**.
2. **게임**을 선택합니다. 기본값은 유로트럭 2입니다.
3. **게임 없이 움직임 미리보기**를 켜서 강도를 확인하고, 실제 주행 전 끕니다.
4. **전체 강도**를 조절합니다. 0%는 정지, 100%는 기본, 200%는 입력에 더 민감하게 반응합니다. 축별 최대 이동·회전 범위는 넘지 않습니다.
   **입력 증폭 (배)**은 1~20배로 조절합니다. 유로트럭처럼 입력이 작으면 전체 강도 100%에 입력 증폭 5배부터 시험하고, 필요하면 10배까지 올려 보세요. 기본 1배는 기존 반응을 유지합니다. 최대 범위에 자주 닿으면 배율을 낮추세요.
   **미세 입력 감도 (%)**는 작은 노면 진동을 더 강조합니다. 0%는 기존 반응이며 50%부터 시험하세요. 빠른 진동이 부드러움에 묻히면 부드러움을 20~40ms로 낮춰 보세요. 실제 입력의 잡음도 강조되므로 정차 중 떨림이 심하면 감도를 낮추면 됩니다.
5. 좌우·상하 이동의 최대 픽셀과 최대 회전 각도, **회전 중심 가로/세로**, **전후 최대 확대·축소**와 **전후 쏠림의 최대 상하 이동**, 방향 반전, 부드러움을 조절합니다. 전후의 두 값을 각각 0으로 설정하면 해당 효과만 끌 수 있습니다.
6. **실시간 데이터 창 열기**를 누르면 별도 창에서 초당 5회 갱신되는 데이터를 보면서 필터 값을 조절할 수 있습니다. 실제 입력 6축, 속도·RPM·기어, 마지막 수신 경과 시간·패킷 수, 최종 이동·회전·확대 비율을 표시합니다. 미리보기 입력은 실제 게임 입력과 구분해서 표시합니다. 기존 **연결 상태 / 수신값 새로고침**은 버튼을 누를 때 갱신됩니다.

시작값: 전체 100%, 좌우 24px, 상하 16px, 회전 3°, 전후 확대·축소 ±5%, 전후 상하 이동 12px, 부드러움 100ms. 픽셀은 캔버스가 아닌 **원본 소스 해상도 기준**이므로, 작게 축소한 캐릭터에는 이동량을 더 크게 잡을 수 있습니다.

같은 게임·포트·LAN 설정을 선택한 필터는 수신 스레드를 공유합니다. 각 필터의 강도와 미리보기는 독립적입니다. 단, OBS에서 같은 소스를 여러 장면에 **참조로 재사용**하면 필터도 공유됩니다. 서로 다르게 움직이려면 소스를 복제하거나 별도 장면으로 감싸세요.

## 이동과 가장자리

- 좌우 가속도 → 수평 이동 및 기울어짐, 상하 가속도 변화 → 수직 이동, 차체 롤 변화 → 회전.
- 전후 가속도 → 가속 시 축소·상승, 제동 시 확대·하강. **전후 반응 방향 반전**은 두 효과를 함께 반전합니다. 전체 강도 100%·입력 증폭 1배에서 0.5G가 설정한 최대값에 대응하며, 5배에서는 0.1G가 최대값에 대응합니다. 일정 속도로 달리면 전후 가속도가 줄어 원래 크기로 돌아옵니다.
- 노면 요철과 전후 쏠림의 상하 이동은 합산됩니다. 예를 들어 16px + 12px이면 최대 상하 이동은 28px입니다. **상하 방향 반전**은 합산된 이동에 적용됩니다.
- 중력과 지속적인 차체 경사는 천천히 기준값으로 흡수합니다. 현재 화면 표현에는 피치·요를 사용하지 않습니다.
- **회전 중심 가로/세로**는 0~100%로 조절합니다. 기본 50/50은 중앙, 50/100은 하단 중앙입니다. 캐릭터 발이 소스 아래쪽에 있다면 하단 기준으로 기울일 수 있습니다. 좌표는 투명 여백을 제외한 원본 소스 기준입니다. 중심을 바꿔도 회전이 0이면 위치는 바뀌지 않습니다. 전후 확대·축소는 이미지 중앙을 기준으로 적용됩니다.
- 입력이 0.5초 동안 끊기면 지정한 시간 상수로 원래 위치·크기에 부드럽게 접근합니다. 복귀 시간은 정확한 완료 시각이 아닌 완화 속도입니다.
- **투명 여백 0**은 소스의 원래 크기와 배치를 유지합니다. 전체 화면이 불투명하면 움직일 때 가장자리가 잘릴 수 있습니다.
- 여백을 추가하면 잘림을 줄일 수 있지만 소스 크기가 바뀌므로 배치를 한 번 조정해야 합니다. 필터를 비활성화하면 추가 여백도 사라집니다.

### 0.2.0 업데이트

전후 효과가 추가되었습니다. 기존 필터도 새 설정값이 없으면 기본 ±5% / 12px를 사용합니다. 기존 동작을 유지하려면 전후 두 값을 0으로 설정하세요. 게임용 DLL의 수신 형식은 그대로이므로 **OBS 플러그인의 DLL과 data 폴더만 함께 교체**하면 됩니다. OBS를 종료한 뒤 설치 스크립트를 게임 경로 인수 없이 실행하세요.

### 0.3.0 업데이트

회전 중심 가로/세로 설정이 추가되었습니다. 기존 필터는 기본 50/50으로 동작합니다. OBS DLL과 data 폴더를 함께 업데이트하며 게임 DLL 교체는 필요 없습니다.

### 0.4.0 업데이트

필터 설정에 실시간 데이터 창을 추가했습니다. 설정창의 슬라이더를 조작하면서 수신값을 확인할 수 있고, 필터를 삭제하면 해당 데이터 창도 닫힙니다. OBS DLL과 data 폴더를 함께 업데이트하며 게임 DLL 교체는 필요 없습니다.

### 0.5.0 업데이트

**입력 증폭 (배)**을 추가했습니다. 중력·상시 기울기를 제거한 뒤 작은 움직임을 증폭하며, 최대 이동·회전·확대 범위와 부드러움은 기존 설정을 따릅니다. 실시간 데이터 창의 실제 입력값은 증폭하지 않습니다. 기존 필터는 기본 1배로 유지됩니다. OBS DLL과 data 폴더를 함께 업데이트하세요. 게임 DLL 교체는 필요 없습니다.

### 0.6.0 업데이트

**미세 입력 감도 (%)**를 추가했습니다. 작은 입력을 더 많이 강조하는 연속 곡선으로, 최대 감도에서 0 근처의 입력에 약 10배 추가 감도를 제공합니다. 0%는 기존 반응을 유지하며, 입력이 없으면 진동을 생성하지 않습니다. 최대 범위·부드러움·복귀 시간은 기존 설정을 따릅니다. 0.5.0 입력 증폭도 포함하며 OBS DLL/data만 함께 업데이트하면 됩니다.

## UDP 게임

게임 텔레메트리 수신 주소는 같은 PC일 때 `127.0.0.1`입니다. 게임과 필터의 포트 번호를 같게 설정하세요. 예: Forza 5300, FH6 5301, F1 20777. 포트는 직접 지정할 수 있습니다. F1은 지원되는 2023/2024/2025 패킷 형식을 선택합니다.

기존 Motion OSC Bridge 등 같은 포트를 쓰는 프로그램은 종료하세요. 포트가 사용 중이면 필터가 오류를 표시하고 재시도합니다. 다른 PC에서 보내려면 LAN 수신을 켜고, 송신 주소를 OBS PC의 IP로 설정합니다.

## 개발 및 검증

배포 ZIP의 `source/`에 같은 버전의 프로젝트 소스 ZIP이 포함되어 있습니다. Python·컴파일러·RTK는 개발 명령에 사용되며 플러그인 실행에는 필요하지 않습니다.

```powershell
rtk proxy python scripts/bootstrap.py
rtk proxy python scripts/build.py --test all
rtk proxy python scripts/build.py --smoke
rtk proxy python scripts/build.py
rtk proxy python scripts/package.py
rtk proxy python tests/package_test.py
```

SCS SDK는 공식 1.14를 `.deps/scs-sdk`에 사용합니다. 자세한 내용은 `docs/truck-setup.md`를 참고하세요. Python은 빌드에만 필요하며 설치된 DLL 실행에는 필요하지 않습니다.

테스트는 실제 C++ 코덱, 로컬 UDP·공유 메모리 수신, SDK 콜백 시뮬레이션, OBS DLL 로딩·D3D11 이미지 렌더링을 검증합니다. 게임을 실제로 주행하며 감각·방향·강도를 조정하는 검증은 별도로 필요합니다.

## 문제 해결

- **필터가 목록에 없음**: OBS를 재시작하고 DLL과 data를 함께 설치했는지 확인합니다. x64 OBS가 필요합니다.
- **주행 데이터 대기 중**: 실제 주행 상태에서 미리보기를 끄고 실시간 창을 확인합니다. 트럭은 게임 DLL 경로와 게임 재시작 여부를, UDP 게임은 주소·포트와 중복 수신 프로그램을 확인합니다.
- **너무 약한 움직임**: 입력 증폭 5배, 미세 입력 감도 50%, 부드러움 30ms부터 시험합니다. 최대 범위에 이미 닿았다면 축별 최대값을 조절합니다.
- **정차 중 떨림**: 미세 입력 감도·입력 증폭을 낮추거나 부드러움을 높입니다.
- **캐릭터 가장자리 잘림**: 투명 여백을 조금 추가하고 소스 배치를 조절합니다.

오류를 제보할 때는 플러그인 버전, OBS 버전, 게임, 필터 설정, 실시간 창의 수신 상태와 관련 OBS 로그를 함께 제공하면 확인에 도움이 됩니다.
