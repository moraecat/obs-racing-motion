OBS 레이싱 모션 0.6.0 — Windows x64

게임의 움직임에 맞춰 OBS 소스를 이동·회전·확대/축소하는 효과 필터입니다.
Python, Warudo, VMC 중계 프로그램 없이 실행됩니다.
검증 환경: OBS Studio 32.0.2 / Windows 11 x64 / Direct3D 11 / SDR.

1. ZIP 전체를 폴더에 압축 해제합니다. ZIP 안에서 바로 설치하지 마세요.
2. OBS를 종료합니다. 게임용 DLL을 설치할 때는 해당 게임도 종료합니다.
3. 사용할 게임에 맞춰 아래 실행 파일 하나를 실행합니다.
   - Install-OBS.cmd: OBS 플러그인만 설치합니다.
   - Install-ETS2.cmd: OBS 플러그인 + 유로트럭 2 게임 DLL을 설치합니다.
   - Install-ATS.cmd: OBS 플러그인 + 아메리칸 트럭 게임 DLL을 설치합니다.
   게임 설치에서는 게임의 최상위 폴더를 선택합니다(bin/win_x64가 들어 있는 폴더).
   Steam > 게임 속성 > 설치된 파일 > 찾아보기에서 위치를 확인할 수 있습니다.
   쓰기 권한 오류가 나면 해당 cmd 파일을 우클릭하여 관리자 권한으로 실행하세요.
4. OBS를 켜고 움직일 소스의 필터 > 효과 필터 + > 레이싱 모션 — 게임 직접 수신을 추가합니다.
5. 게임을 선택하고, 게임 없이 움직임 미리보기로 먼저 확인합니다.
6. 실제 주행 전 미리보기를 끄세요. 유로트럭은 게임의 SDK 알림이 나타나면 확인합니다.

유로트럭 시작 설정 (자동 적용되지 않음)
  전체 강도 100% / 입력 증폭 5배 / 미세 입력 감도 50% / 부드러움 30ms
  캐릭터 발 부근을 회전 기준으로 쓰려면 회전 중심 가로 50%, 세로 100%.
  움직임이 과하거나 정차 중 떨림이 심하면 증폭·미세 감도를 낮추세요.

실시간 데이터 창 열기를 누르면 실제 수신값과 적용된 움직임을 보면서 조절할 수 있습니다.
Forza/F1 계열은 게임의 텔레메트리 송신 설정이 필요합니다. README.md를 참고하세요.

업데이트: OBS 종료 후 다시 설치하세요. 기존 이 플러그인 파일은 백업됩니다.
제거: OBS 종료 후 C:/ProgramData/obs-studio/plugins/obs-racing-motion 폴더를 삭제합니다.
게임 DLL 제거는 해당 게임 종료 후 bin/win_x64/plugins/racing-motion-scs.dll만 삭제합니다.
OBS 장면·프로필은 설치 대상이 아닙니다.

기존 버전에서 갱신해도 새 옵션은 입력 증폭 1배·미세 감도 0% 기본값을 사용합니다.
