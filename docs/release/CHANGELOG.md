# OBS Racing Motion — 0.6.0

Windows x64 배포판 · 2026-09-08

## 포함 기능

- OBS 필터에서 게임 텔레메트리 직접 수신
- 좌우·상하 이동, 2D 회전, 가속·제동에 따른 확대·축소와 상하 쏠림
- 전체 강도, 축별 최대 범위, 방향 반전, 회전 중심 조절
- 입력 증폭 1~20배와 미세 입력 감도 0~100%
- 실제 수신값·미리보기·출력 움직임을 구분하는 실시간 창
- ETS2/ATS 게임용 SDK DLL, 한국어·영어 필터 UI

## 버전별 추가 사항

| 버전 | 변경 |

| 0.5.0 | 입력 증폭 배율 |
| 0.4.0 | 실시간 데이터 창 |
| 0.3.0 | 회전 중심 가로·세로 조절 |

| 0.1.0 | 게임 직접 수신, 이동·회전, 트럭 SDK DLL |

## 검증 범위

OBS 32.0.2 / Windows 11 x64 / Direct3D 11 / SDR에서 DLL 로딩과 렌더링을 검증했습니다.
게임 패킷·공유 메모리·SDK 콜백은 자동 테스트로 검증했습니다. 모든 지원 게임의 실주행 검증을 뜻하지 않습니다.
HDR, macOS/Linux, 다른 OBS 버전은 검증하지 않았습니다. FH6 형식은 기존 브리지에서 이식한 형식으로 실게임 재검증이 필요합니다.

## 기존 사용자

OBS를 종료하고 DLL과 data를 함께 업데이트하세요. 게임 DLL 형식은 변경되지 않았습니다.
입력 증폭은 1배, 미세 입력 감도는 0%가 기본값입니다. 새 옵션을 사용하려면 직접 올려 주세요.
